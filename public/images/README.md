# NSS PESMCOE photo assets

The photographs and official marks in this folder were extracted from the NSS orientation reference PDF.

- `logo/` contains the NSS and PES Modern College of Engineering marks.
- `hero/` contains the main NSS group photograph.
- `activities/` contains the activity photographs used across activity cards and the gallery.
- `camp/` contains winter camp and community field photographs.

Keep the original aspect ratio when placing logos. Activity photographs can be cropped with `object-fit: cover` where a card layout requires it.
